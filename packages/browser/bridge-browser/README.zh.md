# DSH Stride 浏览器 Bridge

[English](README.md) | 中文

`@eilyeee/dsh-browser-stride`
Bridge 在本机 DeepSeek Harness Host 上提供只允许回环访问、需要 token 的 WebSocket，并注册文本形式的 `browser_*` 工具；页面操作由浏览器扩展执行。安装步骤和当前限制见[仓库首页](../../../README.zh.md)。

## 视口图片

`browser_screenshot` 验证原连接扩展返回的有限 JPEG，通过 Host 附件服务保存，并渲染为原生图片块。PTC 会把成功的图片内容附加到下一次模型请求；结构化返回值只提供持久附件引用和截图元数据。`browser_click_at` 是正常审批的写操作，要求单次截图引用和图片比例坐标，并沿用请求、文档、会话及运行控制版本的检查。两者都需要协商可选的 `visualViewport` 能力。DOM 快照仍是文本，原生 CDP 输入尚未实现。使用方法见 [Chrome 视觉工具说明](../../../extensions/dsh-browser/README.zh.md#画布与设计稿)。

## 读取设计稿样式字段

选中图层后，可调用 `browser_read_design_styles`，把页面明确显示的中英文属性标签整理成固定字段：宽高、填充色、文字颜色、圆角、边框、字体、字号、字重、行高、字间距和不透明度。每个已读字段保留 `value` 与原文 `evidence`，另列 `missing` 和 `conflicts`。`parsed` 表示识别到带唯一图层名的部分属性，不代表所有样式都已取得或完成了业务核验。

已知属性面板的 CSS 选择器时，可传入 `{ "region": "#properties" }`；需要 iframe 时沿用 `frame`。省略 `region` 会读取有长度限制的页面文字。当前支持“标签: 值”“标签：值”和相邻的标签、值两行；颜色支持十六进制、`rgb/rgba` 及 HEX 加透明度百分比，明确标注的颜色样式名称也可保留原文依据。简单纯色 `background` 与 `background-color` 均可读取；圆角支持一至四个值，并按等价的 CSS 简写归一化，原文不丢弃。渐变和椭圆圆角等暂不解析。不识别的布局返回 `unrecognized` 或缺项，可退回快照人工判断。没有唯一图层名、存在冲突或不支持的值时，已识别的部分标为 `partial`；冲突及不支持的字段不择一输出，多图层混在一起时不合并尺寸。文字被截断则返回 `content-truncated`，应缩小读取区域。

面板中的具体字体名称记为 `fontFace`，CSS 字体族记为 `fontFamily`，两者分别保留。颜色透明度也与图层整体的 `opacity` 分开，不能相互代替。字体名称包含 Medium 等字样时，仍只按面板明确显示的 `fontWeight` 报告字重。

支持的等价写法会合并原文依据，例如 `#fff` 与 `rgb(255, 255, 255)`、透明度 `50%` 与 `0.5`；数值不同的记录仍会保留为冲突。若格式已识别但字段全部因冲突被拦住，状态为 `partial`，应缩小读取区域或核对选中图层；只有没有识别到支持的属性时才返回 `unrecognized`。

背景与文字仍须分别选中、分别读取。工具不会从像素恢复图层，不会从字体名称猜字重，不会给无单位数值补上 `px`，也不会自动生成或合并 CSS。它在 Host 复用原有 `browser_get_text` 请求，保留页面授权、内容分享、确认、会话和取消检查；没有新增线协议动作。配套扩展的文本读取会保留换行；更新时须重启 Host 并重载扩展，旧扩展可能因压平属性行而无法识别。源码见[读取工具](src/tools.ts)与[标签解析](src/design-inspector.ts)。`node scripts/smoke-visual.mjs` 已通过合成页面的字段读取、切稿和撤销控制检查；`STRIDE_REAL_MODEL=1` 已用现有默认模型验证两层均调用新增工具并给出精确结果。2026-11-04 又在常用 Chrome 的真实蓝湖页面验证了背景、文字分别读取，放大视图后默认模型用五次请求、九次浏览器调用完成精确回读。该结果只覆盖所测稿件和界面，不能代表所有蓝湖布局或自动缩放均已支持。

结构化样式也不能证明页面布局已还原。修改生成页面时，应核对选择器是否实际命中目标，以及渲染后的外边距、内边距和相邻间距。未读到的间距应标为未知，保留已有值，不能补成 0；例如类名相同不代表 `:first-of-type` 会选中这个类的第一项。

## 配置

首次连接可在扩展设置中点击「连接本机 DSH」，再在已登录的 DSH「设置 → 通用 → 浏览器配对」中核对校验码并确认。请求只在内存中保留五分钟，最多八个；只有通过 Connection 登录和 owner 检查的接口可以确认。请求证明与安装凭据不进入 Host 页面或 URL。凭据领取只进行一次，丢失回复、重启或存储失败后需重新确认。手动配对码仍可使用。普通源码更新保留原扩展安装与 Host 数据时无需重配；更新流程见仓库首页。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `token` | 自动生成 | 配对管理令牌；未配置时保存在 `DSH_HOME/ext-bridge-token`，限制文件权限。它不能作为浏览器凭据，不在日志中输出。 |
| `allowHostManagement` | `false` | Host 单独授权设置、凭据及本地路径方法；连接浏览器本身不会授予这些权限。 |
| `pairingProfile` | `web` | `DSH_HOME/browser-bridge-pairings` 中安装级凭据及浏览器任务存储域的命名空间；同一存储根目录和命名空间只能由一个 Host 进程持有。 |
| `toolTimeoutMs` | `90000` | 单次工具超时，单位毫秒。 |
| `snapshotMaxChars` | `32000` | 快照字符上限，最小 500。 |
| `maxInteractiveItems` | `60` | 单次快照交互元素上限。 |
| `sessionWorkspacePath` | `DSH_HOME/browser-sessions` | 扩展会话的工作区；空字符串关闭分组。 |
| `deferSessionCreate` | `true` | 第一条提示发送时才创建会话。 |

`/ext/bridge-config` 只提供本机 WebSocket 地址。配对管理接口仅限本机，要求单独的管理员令牌并拒绝浏览器 Origin 请求；一次性配对码五分钟后失效，Host 只持久化安装级凭据的哈希。签发、查看和撤销命令见仓库首页。扩展凭据保存在扩展源的 IndexedDB 中，包括无法限制 `storage.local` 访问的 Firefox。

[线协议](src/protocol.ts)与[执行契约类型](src/contracts/)是不同层次。Host 通过 `ctx.browserRuns` 向可信插件提供排队任务创建、带版本检查的状态变更、暂停/恢复/停止、不可变动作事实，以及按声明判据检查完成状态。事实必须由可信 Host 代码提供，工具返回的成功文本不能直接作为已验证证据。浏览器工具使用其派发账本和显式执行上下文。侧栏可查看和控制已有运行，包括让符合条件的暂停任务在已选页面继续；任务创建及事实记录仍由可信 Host 代码负责。

可信 Host 使用 `withExecution(runId, controlRevision, async () => { /* 等待浏览器工具调用完成 */ })` 执行运行中的工作。Bridge 从该异步上下文取得运行、会话和控制版本，模型参数不能授予权限。存在活动运行或待对账效果的会话不能退回无上下文派发；无归属的调用也不能绕过活动运行。其他未接管的旧会话保持原行为。

暂停、停止、恢复、阻塞、未决事实、存储故障或关闭会撤销旧上下文。恢复后须由可信 Host 按新控制版本重新进入上下文，旧回调和未等待的后台子任务不会继承新权限。扩展在浏览器派发前通过 `bridge.tool.confirm` 核对原始请求、动作摘要、会话和运行/控制版本。Host 会独立于 RPC 异步链重新检查原执行对象；复制 ID 不能创建上下文。确认只能使用一次，且属于原连接。取消会撤销等待中的确认，包括等待审批的请求；已经派发的效果仍可能未知。账号/租户识别、通用网站业务核验和自动恢复仍未实现。

托管运行的首次页面调用确认后，会固定扩展签发的不透明标签页/绑定标识。后续调用将该标识加入命令摘要，并检查原生绑定仍有效。同标签页导航可以继续；重新绑定、标签页生命周期或窗口变化、连接更换会使旧标识失效。Host 在连接替换后仍记住原连接归属，worker 重启后也不会重建缺失的旧标识。已选页面交接会先登记新目标，再发布运行中的新版本；该文档须保持有效直到首次执行确认成功，之后可正常在同标签页导航。两端缓存只存在于进程内，最多 5,000 项且不自动淘汰；这不识别页面账号或租户。托管运行的新建/跟随/关闭标签工具仍在记录派发之前拒绝；暂停任务只能由用户明确绑定页面并点击继续来交接。

尚未收到回执的写入会阻止启动、恢复或进入新的执行上下文。未决写入及失败的写入回执也会阻止后续派发，因为失败前可能已有部分效果。晚到的成功回执可以明确传输结果，但不会恢复旧上下文或证明业务成功。目前没有自动对账入口。

服务要求 DSH `storageDomain`，存储域名称为 `browser_runs_<pairingProfile 的 UTF-8 十六进制编码>`，使用 Host 配置的存储后端。默认 JSON 后端以私有文件原子写入，不协调共享同一存储根目录的多个 Host 进程。重新打开存储时，未结束的执行上下文会增加控制版本以失效旧指令；运行中记录变为阻塞，停止中记录仍保持停止中。恢复支持实现之前，这类记录不能续跑，也不会重放浏览器动作。目前没有原始任务记录或事实 RPC，也没有侧栏任务删除入口。请按仓库首页执行检查，并单独验证真实浏览器行为。

存储写入失败后，必须重新打开存储域才能继续写入。同一会话存在未对账副作用时，也会阻止其他任务启动。每个任务最多记录 128 项不重复的必需判据和 256 条不可变动作事实。存储状态只是记录，不是浏览器动作的派发许可。

## 明确发起网页任务

存在 DSH 人类命令服务时，`/browser <目标>` 会为接收命令的 Agent 创建排队任务，不由模型判断是否创建。等待任务须由扩展的真实启动操作捕获原生页面，且 Host 先登记目标后才进入运行；「绑定并开始」使用当前选中的已授权页。命令请求的取消信号不控制持久任务的生命周期。选页和任务控制仍在扩展完成；本轮没有另做 DSH 任务面板，也不包含 CLI 或桌面端支持。

Chrome 中，Host 提供 `task.canStartNewPage` 时，排队任务还会显示「新建页面并开始」。用户须已保存自动控制设置，并输入完整、不含用户名或密码的 HTTP(S) 网址。创建标签页前，worker 通过 `bridge.browserTasks.preparePage` 提交任务、会话、记录版本、控制版本和网址。Host 返回仅属于原连接的一次性启动凭据，未使用时 45 秒过期。创建、授权、分组和绑定新页共用现有写队列；worker 固定原生页面标识后，才带启动凭据、原始网址和最终目标网址调用 `bridge.browserTasks.start`。预留和建页都不会启动 Agent。普通侧栏 RPC 转发不能调用预留、取消或启动接口。

确认尚未启动时，失败清理只撤销本次创建取得的控制权并尝试关闭本次新页；用户已接管时保留页面，关闭失败不会报告为成功。启动请求发出后，回执丢失或结果不明时保留页面与绑定，不重试。已使用的启动凭据不能取消或复用。若任务仍排队但启动结果不明，会阻止再次启动；先核对页面和任务，再明确停止该任务后另建。预留和绑定仅存于当前进程，分别最多 5,000 项，不能用来恢复执行。任务中的模型仍不能新建、跟随或关闭标签页。Firefox 保留选页启动。这些可选接口和字段兼容线协议 v4；使用新入口须同时构建和重载两端。

Host 在新的 `withExecution` 上下文中驱动现有 Agent，仅开放已注册的浏览器工具及 PTC 传输。PTC 程序的直接 Node API 仍遵循 DSH 会话原有沙箱；工具注册表限制不等于独立的文件或网络沙箱。PTC 回调跨越异步边界时，只能凭仍有效的原始 Host 父调用标识进入子上下文，复制线协议 ID 不能创建权限。暂停和停止会撤销浏览器上下文并取消所属 Agent 活动；停止须等活动结束后才确认。DSH 的用户取消信号只停止原控制版本，等待所属活动或核验退出后确认，不能停止后来明确继续的新一轮。取消前已保存的证据保留，但不据此完成任务。所属活动期间的新用户输入会中断任务，本轮不支持边执行边通过对话调整。任务目标不能原地修改，计数不能减少；修改目标须停止后新建。

初始上限为主动执行五分钟、十次 Agent 模型请求接纳（包括重试）、二十次浏览器调用（包括 PTC 子调用）。扩展审批等待及人工暂停不计入主动时间，继续时沿用原计数，原有单工具超时仍适用。这些是初始保护上限，不是性能承诺。达到上限后停止新增操作，不重放未决写入。任务记录保存用户目标、单调递增的计数与固定结果码；派发记录仍不保存参数和结果原文。

已保存的任一累计计数达到上限时，Host 会在登记原生目标或改变任务状态前，以 `budget-exhausted` 拒绝启动和继续。侧栏不再显示启动或继续按钮，停止按钮保留；需要处理剩余工作时，先停止旧任务再新建。暂停或更换页面不会重置上限。已经接纳的活动仍可完成可信核验，不会仅因请求或调用次数刚好到上限就否定其结果。

持有任务原生页面绑定的浏览器连接关闭、被替换或被撤销时，Host 会立即让该任务的原控制版本失效，并取消其中的 Agent 活动，再保存暂停状态及 `pauseReason: 'browser-disconnected'`，保留计数和动作事实。新页初次启动尚在提交时断连，也受这层限制。旧连接的迟到事件不能暂停后来继续的控制版本。普通聊天及非任务的自定义执行器沿用原有生命周期。

连接恢复不会续跑任务。请从历史会话选择原任务对话，确认目标页已授权并绑定，再点击「在已绑定页面继续」。原生交接会预留新控制版本，等待原 Agent 活动结束后才继续执行，累计上限不会重置。等待中、未决或失败的写入仍会阻止继续，不自动重放动作。Host 重启后仍需恢复支持，不能用此入口重建旧页面绑定。暂停原因是可选的线协议 v4 字段，旧侧栏会显示通用暂停提示。若连接被其他客户端替换，可在设置点击「保存并连接」重新连接原地址；保活和单独保存策略设置不会抢回连接。

任务继续时，本轮结果会回到 `pending`，目标、累计计数及已保存的事实保留。旧控制版本的核验结果即使晚到，也不能覆盖本轮结果。核验取消前消耗的主动时间仍计入累计上限；当前活动仍需取得自己的可信核验结果。

Host 正常退出属于可重试的断连。侧栏开着时，扩展会等待 Host 恢复并使用原凭据重新连接，不需要再次配对。被其他客户端替换的连接仍会停止重试，直到点击「保存并连接」或再次明确发起连接。原任务的执行权限和页面绑定不会恢复，Host 重启后的任务恢复仍未实现。重连本身不会续跑任务，也不会重放网页动作。

两端协商启用 `caps.taskTargetLoss` 后，扩展后台通过 `bridge.browserTasks.targetLost` 提交 `{ runId, sessionId, controlRevision, targetBinding }`，通知原生页面绑定失效。停止页面控制、关闭标签页或绑定失效时，Host 会让原控制版本失效，保存 `pauseReason: 'page-unavailable'` 并暂停任务；通知确认后浏览器仍保持连接。重新授权页面不会续跑任务，等待中或未决写入仍会阻止明确继续，已开始的网页动作不能撤回。

Host 仅凭完全匹配的原连接、会话、控制版本和页面绑定暂停任务。若失效通知先于启动或交接提交到达，原连接保存的撤销记录也会拒绝该绑定。每个连接最多保存 5,000 项，达到容量后关闭该连接，不能漏记撤销后继续执行。交接提交期间失效时，预留的新控制版本会先被限制，再发布运行状态。旧绑定不能暂停后来的任务。通知失败或回执不明时，worker 只关闭原连接，让 Host 按断连处理，不通过新连接重试通知或网页动作。旧的兼容组件不启用这项能力，返回给旧侧栏的状态也会省略新增的暂停原因，保留通用暂停状态。页面失效后立即暂停需要更新两端。

可信 Host 代码可在任务排队时调用 `ctx.browserTasks.registerVerifier(runId, { acceptsTarget, verify })`。核验器须遵守取消信号，并返回独立取得的 `ActionEvidence`；不能核实目标时返回 `undefined`。网页、模型参数或浏览器 RPC 都不能注册核验器。Host 只根据这些证据记录已验证判据；Agent 空闲或成功文案不构成依据。没有核验器、写入未决或核验出错时，任务阻塞并显示待核实；不提供自动对账或重启恢复。合成表单仅存在于 `scripts/fixtures/` 测试夹具中。

可选的 `STRIDE_REAL_MODEL=1 pnpm run test:smoke-task` 使用临时 Host Home、临时浏览器配置和本地合成表单。`STRIDE_MODEL_PATCH` 可指定私人模型及预设配置，`STRIDE_MODEL_CREDENTIALS` 可指定已保存的凭据文件；凭据以私有权限复制到临时 Home，结束后清理，不复制原有会话或浏览器配置。检查会调用已认证的 DSH Web 命令接口并操作真实扩展控件，不代表桌面端或 CLI 验收，也不以模型输出判断成功。

再加 `STRIDE_TASK_NEW_PAGE=1` 可验收新页启动：初始没有页面授权，拒绝脚本合成的点击，并检查新页的调试控制、蓝色分组、精确会话绑定、任务内工具回执及合成站点独立保存状态。测试核验器使用本机地址，不依赖 Chromium 的测试域名映射。

`STRIDE_TASK_DISCONNECT=1` 同样使用新页启动。测试夹具会暂缓返回首次已完成的快照，再由临时认证客户端替换隔离浏览器的连接，检查暂停原因、Agent 已结束活动、尚未发生业务写入，以及断连和重连期间计数不变。之后须真实点击「保存并连接」、选择原历史会话及「在已绑定页面继续」，模型和浏览器才可继续工作；脚本合成的继续点击会被拒绝。检查覆盖前后两个运行控制版本及合成站点独立保存结果。这是受控的连接替换验收，不代表自动恢复或未决写入对账已经实现。

`STRIDE_TASK_TARGET_LOSS=1` 是另一项中断检查：第一次快照完成后，真实点击扩展的「停止控制此页」，核对页面失效暂停原因、Agent 空闲、计数不再增长、授权已撤销、页面仍打开且桥接仍连接，之后明确停止任务。合成设置须始终保持原值；该检查验收的是中断处理，不是业务目标完成。不要与断连场景同时启用。

单独运行 `node scripts/smoke-host-reconnect.mjs` 可使用临时 Host 和浏览器配置检查重连，不调用模型。它在相同端口重启真实 Host，核对自动重连、配对保留及排队任务仍未启动，再用另一个客户端替换连接，确认这种情况仍需真实点击「保存并连接」。这是连接层验收，不代表已支持中断任务恢复。

## 侧栏任务控制

已认证的浏览器连接可用 `bridge.browserRuns.list` 读取 `{ sessionId }` 的状态摘要，并用 `bridge.browserRuns.control` 提交 `{ sessionId, runId, expectedVersion, control }`。控制只接受 `pause` 和 `stop`。Host 检查会话归属和记录版本；仍在排队的控制随其原连接失效。这些接口不会创建任务、授予浏览器权限、记录事实或恢复执行。

可选的摘要字段 `canRetarget` 为无需恢复、没有等待中、未决或失败写入的暂停任务提供「在已绑定页面继续」。用户先在会话上方选择分组内已授权的页面，再点击按钮。worker 检查界面所示的绑定版本和原生目标，生成不透明标识，再以 `{ sessionId, runId, expectedVersion, controlRevision, targetBinding }` 调用 `bridge.browserRuns.retarget`；普通侧栏 RPC 转发不能调用它。Host 检查归属和版本，先登记属于原连接的目标，再持久化 `running`，控制版本按 `target_changed` 和 `resume` 增加两次。旧上下文保持失效，可信 Host 代码须进入新的 `withExecution` 上下文接手；这不会自动启动执行器或续接普通聊天。结果不明确时只刷新状态。线协议仍为 v4；兼容的旧 Host 不提供此能力，旧侧栏忽略该字段。

侧栏在打开且连接时每两秒刷新一次摘要，最多返回 20 项，未结束任务优先，并附总数；不返回判据、事实、页面证据或参数。版本冲突或回复不明确时只重新读取状态，不自动重试控制命令。「停止中」表示执行器尚未确认停止。普通聊天只有在可信 Host 代码创建运行后才出现任务卡片，聊天原有的取消按钮仍单独控制 Agent。

选页启动和继续的错误保留原错误码，并可带 `targetState: 'unchanged' | 'uncertain'`。只有尚未进入目标绑定，且该绑定标识未被此前请求登记时，Host 才会声明 `unchanged`。worker 只在发送前或收到这种明确拒绝后释放本次未使用的预备绑定，让用户刷新后可再次真实点击。已进入绑定、回执丢失或旧 Host 未提供此字段时，会保留绑定，只刷新状态，不自动重试。释放预备绑定不会关闭页面或撤销原生授权。模型及工具调用的计数保存结束后，也会再次检查原任务是否仍有执行权限，再放行后续调用。

## 派发记录

`ctx.browserRuns.dispatches` 记录生产环境中的每次 `browser_*` 派发，包括没有 Agent 会话的调用。它使用独立的 `browser_dispatches_<pairingProfile 的 UTF-8 十六进制编码>` 存储域。Host 在发送前提交请求元数据和摘要，在返回工具结果前提交回执元数据；每次派发前写盘完成后，都会重新检查取消、过期和连接归属。

| 状态 | 含义 |
| --- | --- |
| `prepared` | 已记录请求，尚未提交派发标记。 |
| `sent_unconfirmed` | 已在 socket 发送前提交标记，实际送达情况未确认。 |
| `not_sent` | Host 没有发送，或重启时只发现准备记录。 |
| `unresolved` | 超时、取消、断连或重启后，送达或结果仍未知。 |
| `returned` | 已记录扩展回复的元数据，不代表业务结果已经验证。 |

记录包含 Host 的动作、请求和连接 ID，可选的安装与会话 ID、成对的运行 ID 与控制版本，工具名称，读写分类，SHA-256 请求摘要，时间戳及固定的状态和错误码。原始参数、输入值、页面结果和对端错误消息不写入账本。读写分类与扩展共用，未知工具按写操作处理。存储失败后，后续账本写入和工具派发会停止，直到重新打开存储。同一连接上的晚到回执可以更新未决记录，并保留原来的中断信息；已结束的调用不会因此重新交付结果。动作不会自动重试或重放。

永久删除会话时，会在会话存储删除后清理其已结束的派发记录；存在未结束的运行或活跃派发时拒绝删除。没有会话归属的记录不会自动过期。任务状态与事实记录仍有独立生命周期。

线协议 v4 携带 `{ actionId, requestDigest }` 和明确的执行范围。新账本记录使用 `identityVersion: 4`：命令摘要绑定动作 ID、工具名、参数、可选的会话 ID，以及旧式调用或运行范围，后者包含运行 ID、控制版本及已确认的目标绑定标识。`transportDigest` 单独绑定原始传输元数据。取消、退出执行上下文或连接更换后，原确认不能再次使用。历史 v2/v3 及仅有传输摘要的记录仍可用于审计，不会转换为可重放请求。两端需要一起构建并重新加载；旧二进制可能拒绝 v4 账本记录。

扩展在进入现有审批、目标检查和写队列之前，先向 IndexedDB 提交执行占位。重复 ID 会被拒绝，worker 重启后仍有效；命令摘要变化视为冲突。存储只保留身份、时间戳和接纳/结束阶段。结束标记不能证明回复送达或业务成功，重复调用不会读回缓存的页面结果。容量为 5,000 条且不自动淘汰；存储已满或不可用时拒绝新执行，匹配到损坏占位时拒绝对应动作。Host 删除会话不会清理这些防重放占位。账号/租户识别及自动对账仍未实现；执行确认不会绕过浏览器权限。
